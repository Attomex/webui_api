# WebUI API - Система анализа уязвимостей ПО

Веб-инструмент для автоматизации контроля и анализа уязвимостей на рабочих станциях. Проект разработан в рамках **дипломной работы** по техническому заданию заказчика из **Института биологии Коми НЦ УрО РАН**.

Репозиторий представляет собой монорепозиторий и содержит две изолированные части: `server` (Backend API) и `client` (Frontend).

## 📌 Основной функционал и автоматизация

Главная задача системы - избавить системных администраторов от ручного сопоставления логов безопасности и автоматизировать аудит рабочих станций.

*   **Интеграция со ScanOVAL:** Система работает с отчетами утилиты *ScanOVAL* (российское ПО для контроля уязвимостей). Пользователь загружает файлы отчетов напрямую в веб-интерфейс.
*   **Умное сравнение отчетов:** Реализован алгоритм автоматического сопоставления свежего и предыдущего отчетов по уникальным кодам уязвимостей:
    *   *Проблема осталась:* Код уязвимости присутствует в обоих отчетах.
    *   *Появившаяся уязвимость:* Новый код, которого не было в старом отчете.
    *   *Решенная проблема:* Код уязвимости присутствовал в старом отчете, но отсутствует в новом.
*   **Работа с данными:** Возможность просмотра, загрузки и выгрузки агрегированных аналитических отчетов в формате **Excel**.
*   **Безопасность и администрирование:**
    *   Ролевая модель доступа (2 роли с разным уровнем привилегий).
    *   Сквозное логирование всех ключевых действий пользователей в системе для контроля безопасности.
    *   Встроенный модуль для отправки баг-репортов.

## 🛠 Технологический стек

### Frontend (`/client`)
*   **Библиотека:** React.js (JavaScript)
*   **UI-компоненты:** Ant Design (для построения плотных информационных таблиц и дашбордов)

### Backend (`/server`)
*   **Фреймворк:** PHP / Laravel (используется в режиме чистого REST API)
*   **База данных:** MariaDB (хранение данных пользователей, логов и результатов парсинга отчетов)

## 📁 Структура проекта

*   `/client` - исходный код фронтенд-приложения, формы авторизации, панели администратора и таблиц сравнения.
*   `/server` - серверная логика на Laravel, миграции БД, парсеры файлов ScanOVAL, API-роуты и контроллеры логирования.
